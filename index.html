grok-bot-linux packages

Apt and dnf repositories for the devrecated/grok-bot-linux helper package. The packages contain only MIT-licensed install scripts. Cursor's official Grok Bot build is downloaded and verified on your machine when you run grok-bot-linux-setup (the one-liners below do that for you). Pool: deb/ · rpm/.

Debian / Ubuntu (apt)

curl -fsSL https://devrecated.github.io/grok-bot-linux/install-apt.sh | sudo bash

Fedora / RHEL (dnf)

curl -fsSL https://devrecated.github.io/grok-bot-linux/install-dnf.sh | sudo bash
